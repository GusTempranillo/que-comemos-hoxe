# Que comemos hoxe
### A memoria culinaria da familia

**Que comemos hoxe** é unha aplicación web progresiva (PWA) para a planificación do **xantar diario**, a xestión do receitario familiar e a conservación do coñecemento culinario da familia.

O proxecto está pensado para ser sinxelo de usar, rápido e accesible desde calquera dispositivo, mantendo toda a lóxica de negocio desacoplada do frontend.

## Principios

- Frontend lixeiro, sen frameworks nin compilación.
- Toda a lóxica de negocio centralízase en n8n.
- A IA intégrase exclusivamente a través de n8n.
- A aplicación debe funcionar correctamente tamén sen conexión.
- O coñecemento culinario da familia é o activo máis importante do proxecto.
